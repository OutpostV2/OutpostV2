# Architecture Documentation

This directory holds stable architecture documentation that is broader than a single decision record.

The current governing sources are:

- [`../OUTPOST-MASTER-BUILD-PROMPT.md`](../OUTPOST-MASTER-BUILD-PROMPT.md) for product, architecture, roadmap, and execution rules.
- [`../OUTPOST-DECISIONS.md`](../OUTPOST-DECISIONS.md) for the accepted decision index.
- [`../decisions/`](../decisions/) for individual architecture decision records.

Implementation-specific notes belong beside the relevant code unless they become stable cross-cutting architecture.
